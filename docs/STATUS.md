# Состояние проекта

Мобильный воксельный бокс от первого лица с разрушаемым соперником, интерфейс на русском. Два направления: **веб-прототип** (`src/`, `dist/`, в магазины не пойдёт) и **Unity 6** (`Unity/`, целевая платформа: App Store, Google Play, Steam; решение — `docs/ADR-001-platform.md`). История — в `git log` и отчётах `Unity/ANATOMY-*.md`.
