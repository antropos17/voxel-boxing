# Анатомическая голова: спецификация для Unity

Дата: 23.11.2026. Решение Руслана: голова соперника в Unity строится как настоящая, изнутри наружу, с реалистичной картиной повреждений; по возможностям не хуже версии на JS. Проба (`Unity/`) намеренно упрощала модель ради замера, эта спецификация её заменяет.

Источники: справка по анатомии и травматологии (атласы, таблицы толщины мягких тканей для лицевой реконструкции, биомеханика переломов лицевых костей) и опись реализации на JS (`src/c_vox.js`, `d_models.js`, `f_damage.js`, `f2_teeth.js`, `g2_gore.js`, `g3_ragdoll.js`, `g_game.js`, `e_fx.js`). Где источники слабые, это отмечено в конце.

## 1. Масштаб

- В JS шаг вокселя головы 3,3 мм (решётка около 56×80×71, примерно 318 тыс. ячеек), зубы отдельными телами с шагом 1,3 мм.
- Кожа (1–2 мм), надкостница, оболочки мозга, склера тоньше такого шага. Целевой шаг в Unity — **2,0 мм** (решётка порядка 96×136×120, около 1,5 млн ячеек, из них занято заметно меньше). Запасной шаг 2,5 мм, если проба покажет, что 2,0 не укладывается в бюджет телефона. Выбор шага делается по цифрам пробы, а не на глаз.
- Структуры тоньше одного вокселя (эпидермис, надкостница, твёрдая оболочка, склера, роговица, компактные пластинки тонких костей) задаются слоем в один воксель. Это сознательное утолщение; оно перечисляется в коде одной таблицей, чтобы было видно, где модель отступает от анатомии.
- Зубы, глаза и нижняя челюсть — отдельные объекты (как в JS), зубы с шагом 1,0–1,3 мм.

## 2. Материалы

Один байт на воксель — индекс материала. У материала: цвет на срезе, разброс цвета, прочность, влажность (блеск), кровоточивость, признак «кость/мягкое/жидкость».

| Группа | Материалы | Цвет на срезе |
|---|---|---|
| Покровы | эпидермис, дерма, губа, слизистая, десна, язык | кожа по тону бойца; на срезе тёмно-розовая; слизистая розово-красная, блестящая |
| Подкожное | жир, фасция и апоневроз (в том числе сухожильный шлем), околоушная железа | жир насыщенно-жёлтый, дольчатый; фасция белёсо-серая, блестящая |
| Мышцы | мышца (одна ткань; какая именно мышца — в карте областей), сухожилие | тёмно-красная с волокнами по направлению мышцы; сухожилие белёсое |
| Кость | надкостница, компактная кость, губчатая кость с костным мозгом, хрящ | компакта желтовато-белая; губчатая — розово-красная решётка; хрящ голубовато-белый |
| Полость черепа | твёрдая оболочка, ликвор (жидкость), серое вещество, белое вещество, мозжечок, ствол, венозный синус, артерия | оболочка белёсо-серая; кора серо-розовая; белое вещество кремовое |
| Глаз | склера, роговица, радужка, зрачок, хрусталик, стекловидное тело, зрительный нерв, глазодвигательная мышца, жир глазницы | склера матово-белая; стекловидное тело прозрачный гель |
| Зуб | эмаль, дентин, пульпа | эмаль белёсая полупрозрачная; дентин светло-жёлтый; пульпа розовая |
| Волосы | волосы, бровь, ресница, щетина | по внешности бойца |
| Пустоты | воздух пазух и носовых ходов, полость рта | — |
| Состояния | свернувшаяся кровь, размозжённая ткань | тёмно-бурый; сырой красный |

Относительная прочность берётся из JS как отправная точка (кожа 8,5; жир 8; мышца 12; кость 38; зуб 30; хрящ 14; мозг 18) и уточняется: компактная кость прочнее губчатой, эмаль прочнее дентина, дерма прочнее жира.

## 3. Строение по зонам (снаружи внутрь, мм)

| Зона | Слои |
|---|---|
| Лоб, свод | кожа 1,2–1,5 → жир с перегородками 4–7 → апоневроз 1–2 → рыхлый слой 1–3 → надкостница 0,5 → кость 7–10 (пластинка, губчатый слой, пластинка) → твёрдая оболочка 0,5–2 → ликвор 2–3 → кора 2–4 → белое вещество |
| Висок | кожа 1,4 → жир и фасции 3–6 → височная мышца 8–15 → надкостница → чешуя височной кости **1,4–2,3** (самая тонкая) → оболочка; под костью проходит средняя менингеальная артерия |
| Бровь, глазница | кожа 1,0–1,3 → жир 1–3 → круговая мышца глаза 1,6 → надкостница → надбровный край (толстый) и стенки глазницы (дно 0,5–1, внутренняя стенка 0,2–0,5) → жир глазницы 10–15 → глаз |
| Нос | кожа 1,2–2 → жир 1–3 → носовые кости 1,5–3 вверху, хрящи внизу (перегородка 1,3–2,7; крыльные 1,4–1,5; боковые 0,8) → слизистая и раковины |
| Скула, щека | кожа 1,5–2 → жир 5–10 → фасция 1–2 → скуловые мышцы 2–4 → щёчная мышца 3–5 → скуловая кость 4–8; под щекой верхнечелюстная пазуха |
| Подбородок, челюсть | кожа 1,5–2 → жир 5–10 → подбородочная мышца 3–5, по бокам жевательная → надкостница → тело челюсти 6–12, в нём корни зубов |
| Ухо | кожа → хрящ 2–4 → кожа |
| Затылок | кожа 1,5 → жир 4–7 → апоневроз и затылочная мышца 2–4 → затылочная кость 8–10 (самая толстая) |

Обязательные структуры:

- **Череп** как набор костей со швами (швы — слабые линии для трещин): лобная, две теменные, две височные, затылочная, клиновидная, решётчатая; лицевой отдел: носовые, скуловые с дугой, верхняя челюсть с альвеолярным отростком, нёбо, сошник. Кость свода трёхслойная. **Пазухи** — настоящие пустоты: лобная, верхнечелюстные, решётчатая, клиновидная.
- **Нижняя челюсть** — отдельный объект: тело, угол, ветвь, мыщелковый и венечный отростки, сустав у височной кости. Крепится жевательной, височной и крыловидными мышцами (в JS это три «связки» на сторону — сохранить и назвать по анатомии).
- **Зубы**: 32, с корнями в лунках: резцы, клыки, малые и большие коренные; эмаль, дентин, пульпа. Каждый — отдельный объект с состояниями цел, скол, шатается, выбит (как в JS, где их 16).
- **Глаз**: шар около 24 мм в жире глазницы, шесть глазодвигательных мышц и зрительный нерв; веки с ресницами. Оболочки и содержимое по таблице материалов.
- **Мозг**: полушария с бороздами, кора поверх белого вещества, мозжечок, ствол; оболочка и слой ликвора; верхний сагиттальный синус по средней линии.
- **Мышцы как области** поверх материала «мышца»: лобная, круговая глаза, круговая рта, большая и малая скуловые, щёчная, подбородочная, жевательная, височная, подкожная шеи. У каждой направление волокон: оно задаёт рисунок на срезе и направление разрыва.
- **Сосуды как источники кровотечения**: поверхностная височная артерия, лицевая артерия, сосуды кожи головы, слизистая носа, средняя менингеальная артерия, сагиттальный синус.
- **Внешность**: тон кожи, волосы, борода, цвет глаз, особенности из набора `LOOKS` версии на JS. Исходное состояние головы хранится снимком и восстанавливается перед каждым боем.

## 4. Повреждения мягких тканей

Состояние поверхности и подлежащих тканей, по нарастанию:

1. **Покраснение** — сразу, от слабых ударов.
2. **Отёк** — нарастает секундами; сильнее всего у глаза и носа. Отёк века закрывает глаз (в JS — при среднем отёке века выше 0,36).
3. **Синяк** — кровь под кожей; цвет меняется со временем боя, как настоящий по дням: красно-розовый → тёмно-фиолетовый → синий → зеленоватый → жёлтый. На тёмной коже зелёная и жёлтая стадии почти не видны.
4. **Ссадина** — снят эпидермис, точечная кровь по всей площади.
5. **Рассечение** — кожа лопается там, где её раздавливает о близкую кость: бровь, скула, переносица, подбородок, губа о зубы. Вероятность зависит от расстояния до кости под точкой удара. Направление по зоне: горизонтально у брови и скулы, вертикально у рта (как `tear()` в JS).
6. **Вскрытие слоёв** — по порядку и с цветами из таблицы: кожа, жёлтый жир, белёсая фасция, красная мышца с волокнами, надкостница, кость.
7. **Размозжение** — мягкие ткани превращаются в кашу и отходят лоскутами (в JS пороги накопленной травмы 7, 14, 24, 42: каша, обнажение кости, осколки, разрыв).

Сохранить из JS: 30% общей травмы головы добавляется к каждой зоне; у каждой области свои уязвимость, склонность к отёку, предел отёка и кровоточивость; свисающие лоскуты и нити; перчатки пачкаются кровью.

## 5. Переломы

Порядок по прочности (первое ломается раньше). Значения в ньютонах — ориентир для порядка, в игре они пересчитываются в игровые пороги.

| Кость | Толщина, мм | Порог, Н | Что видно |
|---|---|---|---|
| Носовые кости | 1,5–3 | 100–340 | нос смещён вбок или вдавлен, кровь из ноздрей |
| Дно глазницы | 0,5–1 | 400–1000 | «взрывной» перелом: дно проваливается в пазуху, глаз западает и опускается |
| Чешуя височной кости | 1,4–2,3 | 400–800 | вдавление у виска; при вскрытии — кровь под костью от артерии |
| Угол и мыщелок челюсти (удар сбоку) | 4–8 | 600–800 | челюсть смещена, прикус разошёлся; часто двойной перелом: подбородок и мыщелок с другой стороны |
| Скуловая дуга и скула | 2–8 | 850–2850 | щека уплощена; «тройной» перелом по швам, скула уходит внутрь единым блоком |
| Верхняя челюсть | 3–6 | 970–1220 | Ле Фор I: зубной ряд с нёбом отделяется; II: пирамида с носом; III: всё лицо отделяется от черепа |
| Теменная | 7–10 | 2000–3500 | линейная трещина или вдавленный перелом |
| Тело челюсти и подбородок (удар прямо) | 6–12 | 2500–3100 | разлом по телу или по средней линии |
| Лобная | 7–10 | 3000–4000 | вдавление лба, вскрытие лобной пазухи |
| Затылочная | 8–10 | больше 3500 | практически не ломается кулаком |

Правила:

- Трещина идёт по анатомической линии (шов, тонкое место, линия Ле Фора), а не по сфере вокруг удара.
- Отломок остаётся связным куском кости с прикреплёнными мягкими тканями и смещается; при дальнейших ударах отделяется.
- Нагрузка на кость копится и передаётся от соседних зон (в JS: рот → челюсть ×0,55; глазница ×0,8; скула ×0,85); порог следующего уровня растёт.
- Перелом сопровождается своей картиной мягких тканей: отёк, синяк, рассечение над отломком, подпись.

## 6. Особые события (всё, что есть в JS, на анатомической основе)

- **Зубы**: скол эмали, расшатывание, вылет зуба с корнем, кровь из лунки; капа вылетает при сильном ударе в челюсть.
- **Челюсть**: вывих; перелом; срыв — висит на жевательных мышцах одной или двух сторон, которые рвутся по одной; отрыв; сырой край с лоскутами.
- **Глаз**: закрывается отёком; при переломе скулы и глазницы выпадает и висит на зрительном нерве и мышцах; отрывается при натяжении.
- **Череп и мозг**: трещина, вдавление, пролом; видна оболочка, под ней кора; при следующих ударах выходит мозговое вещество; тяжи.
- **Сдирание лица до кости**, **разрыв головы**, **шея**: культя с мышцами, сосудами, позвоночником.
- **Нос**: смещение, размозжение хрящей, кровотечение.
- **Ухо**: гематома под кожей («ухо борца»), надрыв.

## 7. Кровь

- Кожа головы и лица кровит обильно даже из малой раны; кровь стекает по поверхности под действием тяжести, размазывается ударами и перчатками, через минуты густеет и темнеет до бурого.
- Нос — потоком на губы и подбородок. Ссадина — равномерное просачивание. Артерия у виска — пульсирующая яркая струя.
- Пределы как в JS: число ран, подтёков, частиц, кусков и нитей ограничено, старое вытесняется; постоянные нити (нерв, тяжи) не вытесняются временными.

## 8. Нокаут

Выключает вращение головы, а не сила сама по себе. Хук и апперкот в подбородок — наибольшее оглушение, удар в висок — среднее, прямой в лоб — наименьшее. Множители оглушения из JS это уже отражают (челюсть 1,6; рот 1,5; ухо 1,25; череп 1,2; скула 1,15; нос 1,0; глазница 0,9): сохранить.

## 9. Что нельзя потерять при переносе

1. Сглаживание углов по восьми соседним ячейкам: без него лицо кубическое, а стыки чанков видны.
2. Смещения ячеек (вмятины, отёк, сдвиг отломков) как данные вокселя, которые читает построитель сетки.
3. Быстрый поиск оторванных кусков от точек удара с редким полным обходом; мелкие острова рассыпаются, крупные становятся кусками.
4. Перестройка сетки с бюджетом времени на кадр.
5. Волна «желе» от удара и изгиб шеи в шейдере; шарнир челюсти через вес в вершине.
6. Разная прочность тканей и областей.
7. Снимок исходной головы перед боем.
8. Пределы на куски, комки, нити, раны, подтёки.

## 10. Порядок работы и проверка

**Этап A. Строение.** Голова строится целиком по разделам 1–3, без повреждений. Проверка: инструмент срезов (плоскость в любом месте и под любым углом, снимок среза); тест, который по лучам снаружи внутрь в контрольных точках каждой зоны сверяет порядок слоёв и толщину с таблицей раздела 3 в пределах допуска; снимки срезов: срединный, через глазницы, через висок, через челюсть и зубы.

**Этап B. Мягкие ткани и кровь** (разделы 4 и 7).

**Этап C. Переломы** (раздел 5).

**Этап D. Особые события** (раздел 6) и нокаут (раздел 8).

После каждого этапа: замер из пробы (время кадра, треугольники, память) на том же сценарии и сравнение с бюджетом.

## Что не подтверждено

- Пороги переломов взяты из старых исследований на трупном материале и из вторичных обзоров; угол и скорость удара меняют их в полтора–два с половиной раза. Используется порядок, а не абсолютные значения.
- Толщина жира и мышц сильно зависит от человека; для бойца мышцы толще средних значений.
- Толщина хряща уха и слоя ликвора в источниках дана приблизительно.
- Выдержит ли телефон шаг 2,0 мм с полным набором состояний на воксель — неизвестно до замера.
